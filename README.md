## Path 3 only
**Concept it teaches:** The theory behind an introductory business statistics course, one unit per article: describing data, probability, the binomial distribution, the normal distribution, sampling distributions and the Central Limit Theorem, confidence intervals, hypothesis testing, comparing two groups, and correlation and regression.

**Built for how I learn because:** I already understand the math, so the site doesn't drill calculations. Each article puts one idea inside a business decision I can picture, like an airline overbooking or a bank's fraud alerts. Then it lists the common misconceptions side by side with the correct idea, and ends with concept questions that explain *why* each answer is right or wrong. The simulations let me watch the theory happen, for example sample means turning into a bell curve, instead of just memorizing it.
