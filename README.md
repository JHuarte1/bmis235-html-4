# HTML-4: Statistics Theory Library
**By:** Jack Huarte (JHuarte1)
**Live site:** https://jhuarte1.github.io/bmis235-html-4/stats/

## My path
Path 3. I've been doing well on the calculations in my statistics class but struggling with the theory: knowing why a formula works and what the results actually mean. I picked Path 3 so I could build a study tool aimed at filling in the lack of theory that I have been missing. It explains each unit's theory through stories about real kinds of business decisions. This way it will be more engaging and allow me to better grasp the material.

## By hand vs by AI
**I made:** The prompt that I gave to Claude to create the idea that would help me out in school. I also went through the site and had Claude fix any mistakes or things that I didn't like with the site.

**AI made:** Everything in the `stats/` folder, made with Claude Code (Anthropic):
- `stats/index.html`: the home page listing the units
- `stats/article.html`: the page that shows each article
- `stats/articles.js`: all nine articles, takeaways, misconceptions and quiz questions
- `stats/app.js`: the code that builds the pages, the quizzes, progress saving, and the two simulations (Central Limit Theorem and confidence intervals)
- `stats/stats.css`: the styles, including dark mode and the phone layout

**I checked it by:** I went through each unit and skimmed through the stories that they told. I also tried it each quiz to ensure that they were engaging and testing the correct content. Then I had Claude go through the site one more time and fine tune everything to make sure it is all perfect.

## Path 3 only
**Concept it teaches:** The theory behind an introductory business statistics course. It goes into 9 units covering different concepts that are important to know for any statistics student. 

**Built for how I learn because:** The math has made sense to me in statistics because it is just memorization, which I am good at. However, the theory has been what I have been struggling with as I can't seem to understand the purpose behind the calculations I am doing. This site I made allows me to learn the theory behind each concept and why the calculations I am doing matter. It also will help cement the learning I am doing with the quizzes at the end.
